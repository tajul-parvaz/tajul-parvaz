## What I Build

At be4energy I develop the web layer of **PV solar monitoring and energy management platforms** — the
point where inverter, meter and battery telemetry becomes something an operator can read at a glance.
Live time-series charts, system-state views, yield and consumption breakdowns that stay responsive as
data volume grows.

The hard part is rarely rendering a chart. It is keeping a long-lived dashboard codebase **modular,
predictable and inexpensive to extend** while new device types, metrics and customer requirements keep
arriving. So I invest in reusable components, a clear data-shaping layer between API and view, and code
that reads the same way six months later.

## Engineering Principles

**Readable over clever** — code is read far more often than it is written.
**Reusable over repeated** — a shared component means one fix, not seven.
**Structured over fast** — a clean data layer today prevents a rewrite next quarter.
**Domain-aware over generic** — understanding the energy context makes most UI decisions obvious.
